About Me

A build-first developer who likes tightening structure, clarity, and usability.

I build web projects by starting with the markup, tightening the content structure, and then layering in layout and interaction. That approach helps me keep pages readable, responsive, and easier to maintain.

My recent portfolio work covers SaaS, marketing, e-commerce, and software-tooling concepts. I am looking for a junior web developer role where I can contribute to front-end implementation, refactors, bug fixes, accessibility improvements, and steady product iteration.

Outside of pure UI work, I also build Python and JavaScript projects that strengthen my problem solving, API usage, and debugging habits.

How I Build

The front-end habits I want to bring into a junior role

01

Semantic Layout

Use the right headings, lists, buttons, links, and landmarks so pages make sense before styling is added.

02

Responsive Systems

Build with flexible grids and spacing so the same page feels intentional on desktop, tablet, and mobile.

03

Accessible Interactions

Support keyboard focus, descriptive alt text, usable navigation, and reduced-motion preferences where possible.

04

Clean Project Storytelling

Write honest project descriptions, show the stack clearly, and make it obvious what each build demonstrates.
